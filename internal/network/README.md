# IPv4 网络配置

只依赖 Go 标准库。`ListAdapters`、`Check`、`IsAdmin` 为只读操作；`Validate`、`Plan` 是纯函数，在非 Windows 上也可使用。非 Windows 的实际执行返回 `ErrUnsupported`，`IsAdmin` 返回 false。

UI 必须先展示 `Plan`，获得用户明确确认，才调用 `Apply`。本包不弹窗、不自动提权、不替 UI 收集授权。`Apply` 会重新检查管理员权限和网卡接口索引是否存在；接口索引不是永久硬件身份，UI 应重新枚举后让用户确认。检查和执行之间仍存在设备拔出或索引被复用的竞态。

应用首先通过 `netsh interface ipv4 set address` 设置 DHCP 或主静态地址，该命令会清除原有静态 IPv4 地址和默认网关；随后添加其余地址、网关和 DNS。其他接口和 IPv6 不在配置范围内。操作会中断现有连接；命令顺序执行，失败或取消即停止，已完成和失败步骤均可能改变网络，没有原子性或自动回滚。`Result.Success` 仅表示配置命令执行成功，不保证 DHCP 已取得租约或外网可达。

- DHCP 禁止混入静态地址和网关，但允许手动 DNS；空 DNS 表示自动获取 DNS。
- 静态模式空 DNS 表示清空 DNS，避免保留旧配置。DNS 最多 8 个，顺序保留，不能重复。
- 静态地址最多 16 个；掩码必须连续，允许 /1 至 /32，/31 按点对点语义处理。
- 最多 4 个不同网关，必须属于至少一个配置地址的子网，不能是本机、网络或广播地址。默认路由按列表顺序分配 metric 10、11、12、13；这不是链路健康探测或保证自动故障切换。
- 连通检查目标最多 16 个，只接受单播 IPv4 或 ASCII 主机名，不接受 URL、端口、IPv6、通配符或命令文本。空列表不发起探测；每个目标独立进行 ICMP 检查，失败不代表所有业务连接失败。

所有子进程直接通过 `exec.CommandContext` 调用系统目录中的 PowerShell/netsh，不调用 cmd。PowerShell 只拼入经过白名单校验的接口索引和检查目标，配置名、网卡名不进入命令。每条命令最长 30 秒，枚举 20 秒，整个应用 2 分钟，单目标探测 10 秒；每条命令最多保留 1 MiB 输出。

运行 `go test ./internal/network`。测试只调用 fake runner，不读取或修改本机网络。
